# B2B Marketing Intelligence Lab

An editorial, interactive strategic work sample demonstrating how international B2B marketing can connect product expertise, market understanding, corporate communication, sales enablement and learning.

## Local development

```bash
npm install
npm run dev
```

The prototype is entirely rule-based: it uses no external AI service, database, analytics, authentication or customer data.

## Architecture

- `app/` — Next.js App Router entry points and the visual design system
- `components/` — editorial sections and interactive communication experiences
- `data/` — selectable contexts and composable market/role rules
- `lib/` — deterministic market-approach generation
- `types/` — shared domain models
